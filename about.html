Project overview

A community layer for your existing server.

This starter site gives the project a polished public home while the account website and game services continue operating separately.

What works now

The static site can be published directly through GitHub Pages. Account buttons lead to the existing account website, and the status panel attempts to read its public launcher-status API.

What comes later

A real social network needs a server application and database for posts, comments, friends, messages, notifications, moderation, uploads, and secure profile synchronization. GitHub Pages cannot run those backend services.

Account and rank integration

The existing server already has permanent account identifiers, linked online character slots, public handles, and E–S ranked profiles. A future backend should expose only approved public fields through authenticated APIs. Website roles must stay separate from game rank and server-administrator permissions.

Independent design

The theme is an original cozy field-guide design. It does not include source code, logos, artwork, or written content from monsterpatch.org.
